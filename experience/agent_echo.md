## AgentEcho —— 可验证、可复现的 Coding Agent 经验分发协议

### 一句话定位

> **让 Coding Agent 的经验像代码一样被版本化管理、可复现验证、可自由分发。**

------

### 核心问题

Coding Agent 无法共享成功经验 → 每个任务都被重复解决 → 群体学习无法形成。

------

### 核心方案

一个标准化的“可回放经验包”，包含四层：

| 层级   | 组件            | 作用                         |
| :----- | :-------------- | :--------------------------- |
| 操作层 | tmux 截屏流     | 记录终端操作序列             |
| 状态层 | Git commit 序列 | 记录每次操作后的文件系统状态 |
| 环境层 | Docker 快照     | 锁定系统环境与依赖           |
| 验证层 | 语义 Hook       | 强制执行验收标准             |

------

### 关键规则

> **分享者必须自己能成功回放。**

类比：马里奥关卡作者必须自己能通关。

只有通过“自回放”验证的经验包，才能被标记为可分享。

------

### 核心价值

| 面向         | 价值                   |
| :----------- | :--------------------- |
| Agent 开发者 | 复用他人经验、微调模型 |
| 评测体系     | 可执行的测试用例       |
| 社区生态     | Agent 之间的“GitHub”   |
